# Design Implementation Plan: TareaDetailPage

## Summary
- **Scope:** page (redesign)

## Files to Change
- [ ] `src/app/trabajos/[id]/tareas/[tareaId]/page.tsx` — Main page refactor

## Implementation Steps

### 1. Remove unnecessary useState hooks
- Remove `notas` state (not persisted in DB, remove field entirely or keep as optional)
- Remove `hasChanges` logic — auto-save or explicit save per mode

### 2. Add edit mode state
```tsx
const [isEditing, setIsEditing] = useState(false);
```

### 3. Refactor status section
- Replace standalone card with inline row: icon button + status text + edit toggle
- Icon button: `w-8 h-8 rounded-xl` with green/amber states
- Edit toggle: pencil icon button, primary color when active

### 4. Implement view/edit mode rendering
**View mode (default):**
- Description card: read-only text in `bg-surface rounded-[32px]` card
- Price card: formatted `$15.000` in bold, or "Sin precio" with helper
- Notes: collapsed accordion-style row (just label + chevron)

**Edit mode (toggle active):**
- Description: textarea in card with `border-2 border-primary/20`
- Price: input in card with `border-2 border-primary/20`
- Notes: expanded textarea with same primary border style

### 5. Keep photos section unchanged
- Photos card stays always visible (no view/edit distinction needed)

### 6. Save button behavior
- In view mode: disabled/hidden (no changes possible)
- In edit mode: primary button, calls `updateTask` on click

## Component API
- **Props:** `params: Promise<{ id: string; tareaId: string }>` (existing)
- **State:**
  - `isEditing: boolean` — toggles between view and edit mode
  - `descripcion: string` — synced from task, editable in edit mode
  - `precio: string` — synced from task, editable in edit mode
- **Events:**
  - `setIsEditing` — toggle edit mode
  - `handleSave` — persists changes via `updateTask`

## Required UI States
- **View mode:** Description shown as text, price formatted, notes collapsed
- **Edit mode:** All fields become editable inputs with primary borders
- **Loading:** No loading state needed (data comes from Zustand store)
- **Error:** No error state needed (local store, no network)
- **Empty:** Price null → "Sin precio" with helper text
- **Disabled:** Save button disabled when not in edit mode
