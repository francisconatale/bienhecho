CONCEPTO 03

Movimiento · Micro-interacciones

Entradas suaves, un solo timing, cero ruido
Timing250–280ms
🎬Todo se mueve con la misma curva cubic-bezier(0.2, 0.8, 0.2, 1) y el mismo rango de duración. Nada salta: todo se desliza. Y si el sistema pide menos movimiento, se apaga todo.

Timing

Entrada de página280ms · fade + lift
Slide detalle →280ms · translateX(16px)
Slide detalle ←280ms · translateX(−16px)
Fade de card250ms · fade + lift
Shimmer (progreso)1.6s · skewX(12°) loop

Easing

Curva única
Acelera suave, desacelera suave
cubic-bezier(0.2, 0.8, 0.2, 1)
Accesibilidad
prefers-reduced-motion
Si el sistema pide menos movimiento, todas las animaciones se reducen a ~0ms. El contenido nunca depende del movimiento para entenderse.
