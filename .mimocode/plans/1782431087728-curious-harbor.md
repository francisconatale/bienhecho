# Plan: Paleta de Colores Verde Pastel

## Objetivo
Crear un Design Lab que muestre visualmente la paleta verde pastel para que el usuario pueda ver todos los colores antes de implementar.

## Paleta Verde Pastel (Moderada)

## Implementación

### Paso 1: Crear Design Lab de Paleta
Crear `src/app/palette-lab/page.tsx` con:
- Grid de colores mostrando cada token
- Nombre del token + hex + muestra visual
- Sección Light y Dark side-by-side
- Ejemplo de componentes (botones, cards, inputs) con la paleta
- Toggle para cambiar entre light/dark

### Paso 2: Actualizar globals.css
Reemplazar tokens en `@theme` y `html.dark` con la paleta verde pastel.

### Paso 3: Verificar
- Abrir `/palette-lab` para ver la paleta
- Toggle dark mode para verificar ambos modos
- Navegar a `/presupuestos/nuevo` para verificar integración
